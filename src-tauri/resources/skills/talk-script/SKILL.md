# 广告口播脚本生成 Skill（talk-script）

`talk-script` 是「比拜克胶囊广告脚本」的完整创作工作流，把 bibike 平台原有的一组 Python Agent
（需求补充、检索、生成、润色、风险审查、事实守卫）重写成的 **Skill 指令块**，由云端 codex
（harness-service 内的 execution engine）执行。

> 产品事实与知识库在**云端**，本 Skill 负责「如何正确地创作」——检索、把关与生成规范全部内联在此。
> 所有创作必须挂在 **比拜克胶囊** 的已确认产品事实上，不得虚构。

## 触发

用户表达「写/生成/创作/改 广告脚本」，且内容围绕比拜克胶囊 / 上火 / 牙龈肿痛 / 大便秘结等时激活。
激活后按下面 🅰→🅱→🅲→🅳 有序执行。

## 🅰 需求采集（取代原 BriefIntakeAgent）

- 目标：至少拿到 `目标人群`、`主推卖点`、`表达风格`、`视频时长`；缺则**追问，最多 5 轮**。
- 追问生成规则：
  - 常规型优先补：生活场景（熬夜/吃辣/饮食不规律）、真实困扰表现、人群细分、叙事角度、语气节奏、结尾转化。
  - 促销型优先补：已确认的活动利益、购买顾虑、商业冲突、结尾成交推动；**不要**追问生活场景。
- 禁止询问：产品名称、成分、功能主治、用法用量（这些由系统把握）。
- 用户说「开始生成 / 开始吧 / 就这些 / 不用再问了 / 可以了」→ 立即终止追问，进入生成。

## 🅱 知识库检索（通过云端 /retrieve）

调用云端 harness-service `POST /api/v1/retrieve`，body 携带 `brief`（人群/卖点/风格/时长/模式 content|promotion）。

- 云端返回**按模块清洗后的参考片段**：痛点钩子 / 购买理由 / 信任背书 / 品牌资产 / 促销话术 / 金句库。
- 检索参考段只用于**借鉴表达**：语言、结构、场景、语气、金句；**不得**把历史价格/数量/配送/限时当作新活动事实。
- 促销模式参考段已做中性化（价格→「相应优惠」、日期→「本次」等），沿用即可。

## 🅲 脚本生成（取代原主生成/润色/风险 Agent 指令）

### C1 通用编导规则（原 SCRIPT_GUIDANCE）
写真人口播，不写文章/科普/广告模板：句子长短交错、有停顿呼吸感、删空话与强行因果。开头尽快进入
目标人群真实处境或卖点冲突，不从问候/产品名/空洞口号开始；每段推进理解、信任或购买。只用产品资料和
本次需求确认信息，不得虚构功效、症状、价格、活动、配送、时效、数字；不添加主播/医生/专家等个人资历或
背书；不用「兄弟」「大哥」等称呼。默认单人口播。

### C2 去AI味（原 DE_AI_GUIDANCE）
不要硬塞网络主播套话、网络梗或夸张动词；口语是平实自然有停顿，不是喊麦。不写预告/总结式过渡句。
排比/对仗/反问最多开头一次、两三个短句，不三连及以上。产品事实不罗列成说明书，说一个事实紧跟一句
承接感受。不写用法用量。结尾像熟人说一句具体的话，不喊口号。

### C3 结尾转化（原 CONVERSION_GUIDANCE）
自然推动购买，不用健康总结说教收束。只用已确认的利益点和购买入口；无具体活动事实时仍推动行动，但
不得编造价格/数量/优惠/限时/配送承诺。不解释页面、不重复路径、不固定句式。

### C4 促销模式（原 PROMOTION_GUIDANCE + PROMOTION_MODE_GUIDANCE，作用于 brief.mode=promotion）
按四段推进：开头噱头（第一句只做活动噱头/悬念，不铺生活场景）→ 优惠政策（可模糊制造吸引力，不虚构
具体价格/数字）→ 简短的购买理由+信任背书 → 促销话术收尾（直购渠道/包邮/活动价，落到明确 CTA）。本模式
优先于通用编导规则，允许煽动/催促/制造焦虑，允许连口号/设问/反问，收尾要有命令感。

### 结构要求
最终输出完整口播稿，不含模块标题；同时输出「创作说明」（用到的产品事实、思路、参考模块）与「风险提醒」。

## 🅳 风险与事实守卫（原 ProductFactGuard + 风险审查；输出后执行，不阻断返回）

生成后对**整个脚本**扫描，命中即列进「风险提醒」，**不阻止交付**，交编导人工改：

| 类别 | 禁止 | 级别 |
|---|---|---|
| 未确认功效/症状 | 牙痛、牙龈出血、牙龈鼓包、牙龈起泡、口腔溃疡、牙周炎、消炎、止痛、根治、治愈、杀菌、抗炎、偏头痛、头晕、失眠、半边脸发胀 | block |
| 未请求的用法用量 | 一次2、一日三次、小儿、三岁以内 | block |
| 未确认促销承诺 | 元、折、优惠、活动、包邮、厂家直发、买一送一、限时、底价、促销、送到家、仓库 | block |
| 未确认的数字宣传 | `\d+(mg|毫克|元|折|%)`（允许 11.1） | block |
| 绝对化极限词 | 最、第一、顶级、唯一、绝对、保证、完美、100%、立刻见效、根治、彻底解决 | warn（仅提醒） |

「大便」相关内容只允许：大便秘结/大便不畅/便秘/排便不畅/排便困难/排便不顺。

## 产品事实（可写进口播，不得越界）

- 名称：比拜克胶囊；OTC 正规中成药（可写「OTC」「正规药品」，不写批准文号）
- 成分：熊胆粉、酒大黄、儿茶、冰片、胡黄连、香墨、玄明粉（七味药材）
- 已确认事实：每粒高达 11.1mg 熊胆粉
- 主治范围（可口语化表达，不引述式生抛）：清热、解毒、通便；外感病气分热盛，发热烦躁，头痛目赤，牙龈肿痛，大便秘结
- 禁用越界的「上火以外」扩展：把功能主治/症状做出口语化表达时，**不得新增**「上火」未覆盖的症状名
